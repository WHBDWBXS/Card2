# Card2 Survivor (Godot 4 + C#)

一个 2D 类幸存者项目骨架，覆盖以下需求：

## 已实现核心功能

1. 玩家属性：生命、攻击、移动、体力。  
2. `Shift` 奔跑持续消耗体力，`Space` 冲刺消耗体力；正常移动恢复体力。  
3. 双攻击模式：
   - 近战伤害 = 玩家攻击力 + 近战武器伤害。
   - 远程伤害 = 远程武器伤害（与玩家攻击力无关）。
4. 武器设计：近战 3 把、远程 3 把（默认装备 1 把近战 + 3 把远程）。
5. 按住 `Tab` 临时切换到远程模式，松开回近战；`Q` 切换远程武器。
6. 技能系统：`IPlayerSkill` + `SkillManager` 预留复杂/联动技能接口，附带示例治疗技能。
7. UI 事件接口：右侧体力、头顶生命、脚底名字（由 `PlayerStatusPresenter` 统一绑定）。
8. 怪物在玩家周围随机角度范围生成，并强制限制在地图边界内。
9. 怪物攻击附带击退效果。
10. 受击机制：首次受击触发 0.2 秒无敌和 5 秒计时窗口。
11. 怪物死亡掉落经验结晶，拾取后增加经验和金币。
12. 升级：经验满后升级并提升生命/攻击，弹出升级面板四选一强化（移速/攻击/攻速/冲刺距离）。

## 输入映射（自动注入）

- `WASD`: 移动
- `Shift`: 奔跑
- `Space`: 冲刺
- 鼠标左键: 攻击
- `Tab`(按住): 切换远程攻击模式
- `Q`: 轮换远程武器

## 主要脚本结构

- `Scripts/Player/PlayerController.cs`: 玩家移动、体力、无敌计时、升级入口。  
- `Scripts/Combat/CombatController.cs`: 近战/远程攻击执行。  
- `Scripts/World/MonsterSpawner.cs`: 生成逻辑与地图边界限制。  
- `Scripts/World/Monster.cs`: 怪物追击、攻击、击退、死亡掉落。  
- `Scripts/Systems/SkillSystem.cs`: 技能扩展接口。  
- `Scripts/UI/UpgradePanel.cs`: 升级面板强化选项。  

## 运行

1. 用 Godot 4.2+ 打开项目根目录。
2. 确保安装 .NET 8 SDK。
3. 打开 `Scenes/Main.tscn` 后运行。

> 这是可扩展原型：美术资源、动画状态机、敌人行为树、装备掉落池、技能联动逻辑可在此基础上继续扩展。
